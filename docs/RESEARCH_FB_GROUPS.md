# Дослідження: як люди продають у Facebook-групах (16.10.2026)

Джерело: 13 скрінів від Влада з груп «Куплю лікарські рослини» і «Куплю-продам лікарські рослини».

## Що побачили
| Спостереження | Приклад | Що це означає для Збору |
|---|---|---|
| Ціни в різних одиницях і валютах | «за літр», «100 грам – 50 грн», «відро 5 л 650 грн», USD | Ціна + одиниця (кг / 100 г / літр / шт), тільки грн |
| Фейкові ціни, бо FB вимагає число | «1 ₴», «2 000 USD» за мухомор | Варіант «Ціна договірна» |
| Кілька рослин в одному пості | цвіт конюшини, кульбаби, черемхи, первоцвіт, звіробій | Кілька позицій в одному оголошенні |
| Рукописний прайс на 22 рослини — найпопулярніший пост (103 ❤, 34 коментарі) | Светлана Бован | **Прайс-лист продавця** — таблиця «рослина → ціна» |
| Асортимент ширший за наш довідник | журавлина (свіжа), суха вишня, ягода бузини, пелюстки півонії, нагідки, меліса, каштан, медунка, чебрець… | Розширити довідник + «Інша рослина» |
| Місце — район, а не область | «Овруцький район», «Лубенський район» | Поле «район / місто» |
| Телефон і Viber в тексті | «Тел/Вайбер 097…» | Кнопки Подзвонити / Viber / Telegram |
| Доставка й тара | «Пересилаю Новою», «+50 грн тара» | Позначки «Нова пошта», «Самовивіз» |
| Якість описують словами | «Урожай 2026», «висушений при 45°», «без піску» | Рік збору, свіжа/суха, «чисто, без домішок» |
| Опт і роздріб | «великий опт», «в роздріб та опт» | Позначка «Опт / Роздріб», мін. партія |
| Закупівельники — фірми з банерами | «Плоди України: купуємо каштан від 20 грн/кг» | Значок «Перевірена фірма» (пізніше) |
| Пости губляться, назви обрізані | «Продам+мухомор+черв…» | Наш пошук, фільтри й автоназва вже це вирішують |
